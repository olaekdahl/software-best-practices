Performance Efficiency Design Patterns (Generic Python Demos)
===========================================================

These demos implement the patterns listed on Microsoft Learn's "Architecture design patterns that support performance efficiency" page,
but are intentionally vendor-agnostic and runnable in any environment (stdlib only). Source list: 2026-02-27.

Run a single demo:
    python demos/<pattern>/app.py

Run all demos:
    python run_all.py

Notes
- Each demo is intentionally small and educational, not production hardened.
- No external services required; network calls are simulated unless otherwise noted.
